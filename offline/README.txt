라벨포스 디자인 스튜디오 1.0 — 오프라인 배포 패키지

[빠른 시작]
1. ZIP을 다운로드하여 폴더 전체를 압축 해제합니다.
2. Windows 10/11에서 Install.cmd를 실행합니다.
3. 바탕화면의 LabelPOS Studio 바로가기를 실행합니다.
   설치 없이 사용하려면 Start.cmd를 실행합니다.
4. 라벨 가로·세로 크기를 mm로 설정합니다.
5. 텍스트, 이미지, 바코드, QR 코드 등을 추가하여 배치합니다.
6. 인쇄를 선택하고 실제 프린터 용지를 라벨 크기와 동일하게 설정합니다.

[설치 방식]
Windows 사용자 폴더에 복사 설치됩니다. 관리자 권한이나 인터넷 연결은
필요하지 않습니다. 실행에는 Windows PowerShell과 Edge 또는 Chrome이
필요합니다. EXE/MSI 설치 파일이 아닌 CMD/PowerShell 설치 패키지입니다.
회사에서 스크립트 실행을 제한하면 전산 담당자 확인이 필요합니다.
프로그램은 내 PC의 127.0.0.1:18763에서 실행되며 외부에 서버를 공개하지 않습니다.
웹 버전과 로컬 버전은 서로 다른 저장 공간을 사용합니다. .lpos 파일로 이동하세요.
실행 중인 로컬 서버를 종료하려면 Stop.cmd를 실행합니다.
삭제하려면 설치된 폴더의 Uninstall.cmd를 실행합니다.
폴더: %LOCALAPPDATA%\LabelPOS-Studio

[파일과 저장]
.lpos: 라벨포스 편집 파일. 디자인, 이미지, 데이터, 용지 설정을 함께 저장합니다.
자동 저장/내 디자인은 현재 브라우저의 저장 공간에 보관됩니다.
중요한 작업은 저장 버튼으로 .lpos 파일을 다운로드해 별도 보관하세요.
브라우저 캐시 또는 사이트 데이터 삭제 시 자동 저장 디자인이 지워질 수 있습니다.
엑셀/CSV 첫 행을 열 제목으로 사용합니다. 중복 또는 빈 열 제목은 지원하지 않습니다.
최대 1,000행, 100열, 10MB의 데이터를 한 번에 가져올 수 있습니다.
다중 시트 엑셀에서는 가져올 시트를 선택합니다.
연결 필드: {{상품명}}, {{바코드}} 등 열 이름을 입력합니다.
{{오늘}}은 현재 날짜, {{일련번호}}는 행 데이터 또는 일련번호 설정 값입니다.
데이터 셀을 직접 수정할 수 있습니다. 체크한 행만 일괄 출력합니다.
일련번호 생성은 연결된 데이터를 일련번호 목록으로 교체합니다.

[출력]
롤 라벨: 라벨 크기를 프린터 드라이버에도 똑같이 입력하세요.
A4 시트: 라벨 간격과 시트 여백, 첫 페이지 시작 칸을 설정합니다.
배율 100%, 여백 없음, 머리글/바닥글 해제로 설정합니다.
처음에는 한 장 시험 출력하고 X/Y 보정값을 조정하세요.
기본 출력은 OS 프린터 드라이버와 브라우저 인쇄 화면을 사용합니다.
PDF: 인쇄 화면에서 PDF로 저장을 선택하세요.
ZPL: 설정된 DPI의 흑백 래스터 ZPL 파일을 생성합니다. Zebra 호환 장비용이며
모든 프린터가 지원하지는 않습니다. 모델별 전송 도구/드라이버가 필요합니다.
바코드는 이미지 크기 변경에 따라 모듈 폭이 달라질 수 있습니다.
바코드/QR을 실제 프린터로 출력한 후 스캐너로 판독 검증하세요.

[구현된 기능]
사용자 지정 5~500mm 크기 · 롤/A4 용지 · 203/300/600 DPI
텍스트, 이미지, 선, 사각형, 원/타원, 삼각형
개체 드래그, 크기 조절, 회전, 좌표 입력, 정렬, 그룹, 잠금, 숨김, 레이어 순서
글꼴, 크기, 굵게, 기울임, 밑줄, 색, 글자 맞춤
격자, 1mm 스냅, 확대/축소, 실행 취소/다시 실행, 복사/붙여넣기
CODE128/EAN13/EAN8/CODE39/GS1-128/QR/DataMatrix/GS1DataMatrix/PDF417/ITF14
엑셀/CSV/TSV, 데이터 셀 편집, 연결 필드, 일련번호, 행별 수량 출력
템플릿, 기기 자동 저장, 편집 파일 저장/열기, SVG/PNG/ZPL 내보내기
출력 전 경계/안전 여백/연결 필드/바코드 값 점검
오프라인 브라우저 앱(PWA), Windows 사용자 폴더 설치

[원본 참고 범위와 제한]
첨부 UniLabelDesigner의 배포 파일 내부에서 메뉴 및 기능명을 확인했습니다.
원본 프로그램의 코드/이미지/실행 파일은 재사용 또는 재배포하지 않았습니다.
기능명이 확인된 주요 디자인/데이터/출력 흐름을 독립적으로 구현했습니다.
원본 전체 동작을 실행 비교하지 못했으므로 100% 기능 동등성을 보증하지 않습니다.
.uld/.uldx/.uldxt 전용 파일, 원본 계정/서버 연동, SQL 데이터베이스 직접 연결,
제조사 전용 직렬 통신/프린터 명령, 원본의 특수 글자 효과는 지원하지 않습니다.
인증서가 포함된 서명 EXE/MSI 설치 프로그램은 이 패키지에 포함되지 않습니다.
Linux 환경에서 앱 기능을 검증했습니다. Windows 설치 스크립트 및 실제 프린터
하드웨어에서의 시험은 이 환경에서 수행할 수 없었습니다.
원본 화면 캡처·매뉴얼·사용 중인 프린터 모델을 기준으로 추가 대응이 필요합니다.
