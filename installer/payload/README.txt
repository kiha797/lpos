라벨포스 디자인 스튜디오 1.0.2 — MSI 설치판

설치 완료 후 바탕화면 또는 시작 메뉴의 LabelPOS Studio를 실행하세요.
인터넷 연결 없이 편집·데이터 가져오기·출력을 사용할 수 있습니다.
Windows 10/11 64비트, 기본 Edge와 Windows PowerShell을 사용합니다.
설치 경로: %LOCALAPPDATA%\LabelPOS\Studio
제거: Windows 설정 > 앱 > 설치된 앱 > LabelPOS Studio > 제거
실행 서버 종료: 시작 메뉴의 LabelPOS Studio Stop
중요한 디자인은 .lpos 파일로 백업하세요.
프로그램은 내 PC의 127.0.0.1:18763에서만 실행합니다.
MSI는 디지털 서명되지 않았습니다. Windows 실기기 설치·출력 검증은 별도 필요합니다.

1.0.2: MSI 짧은 파일명 메타데이터 수정 및 자동 설치 로그 지원.
